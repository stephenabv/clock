# Character photos (optional)

Put a photo here to replace a character's cartoon portrait. The file must be a
JPEG named after the character's id:

| Character      | File          |
| -------------- | ------------- |
| Loki           | `loki.jpg`    |
| He Who Remains | `hwr.jpg`     |
| Sylvie         | `sylvie.jpg`  |
| Mobius         | `mobius.jpg`  |
| Ravonna        | `ravonna.jpg` |
| Hunter B-15    | `b15.jpg`     |
| OB             | `ob.jpg`      |
| Alligator Loki | `gator.jpg`   |

Images are shown in a 4:5 portrait frame, cropped from the top center, so
use a head-and-shoulders shot about 400×500 px.
If a file is missing, the clock shows the original drawing instead. Miss
Minutes always uses her drawing.

Only add images you have the rights to use. This site is publicly deployed.
